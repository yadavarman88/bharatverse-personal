# CHANGELOG — Personal Edition

All notable changes made by Arman Yadav on top of the original
BharatVerse (Team Netaji Ninjas, SIH 2025) codebase.

## 2026-10-28 — "Trip Planner & quality pass"

### Added
- **Trip Planner feature** (`src/pages/TripPlannerPage.jsx`,
  `src/utils/tripPlanner.js`):
  - Site picker with search over the full 60-site heritage dataset
    (`src/data/heritage.json`), ordered route chips.
  - Pure-function planning engine: `groupByState`, `buildItinerary`,
    `generatePlan`, `planToMarkdown`.
  - Day-by-day itinerary generated by grouping selected sites by state.
  - Editable budget model: lodging/food/transport/entry fees by travel style
    (budget/standard/premium) and traveller count, with totals.
  - Export to Markdown (download + clipboard) and save/load of the last 5
    plans in localStorage.
  - Validation with inline alerts (1–30 days, 1–20 travellers) + toasts.

### Fixed
- All 8 footer links were dead `href="#"`; footer now navigates to real
  pages and includes the Trip Planner.
- Mobile header overflow: hamburger rendered off-screen below ~440px
  viewport; logo/actions now compact and menu button visible at 312px.

### Changed
- HomePage: removed fabricated "50,000+ explorers" stat and the newsletter
  form that had no backend; replaced with factual CTAs. Art-form stat now
  reflects the real bundled dataset size (60).
- `package.json`: snippet name `frontend` → `bharatverse-personal`.

### Verification
- `npm run build` passes (Vite 7).
- ESLint clean on all files touched by this edition; ~57 pre-existing
  errors remain in untouched original files (documented in README).
- Manual browser QA: planner flow (select → generate → budget → validation),
  homepage hero, footer nav, mobile header at 312px; no console errors
  beyond pre-existing third-party embed warnings.
